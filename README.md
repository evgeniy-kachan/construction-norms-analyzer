# Анализатор строительных норм

Веб-приложение для анализа строительных чертежей и планов на соответствие нормам СП 54.13330.2022.

## Возможности

- Загрузка изображений и PDF файлов с чертежами
- Автоматическое распознавание размеров и элементов на чертеже
- Проверка соответствия нормам СП 54.13330.2022
- Визуализация найденных нарушений
- Интерактивное управление отображением нарушений

## Технологии

- JavaScript (ES6+)
- HTML5 Canvas для визуализации
- Tesseract.js для распознавания текста
- PDF.js для работы с PDF файлами

## Использование

1. Откройте [веб-приложение](https://evgeniy-kachan.github.io/construction-norms-analyzer/)
2. Перетащите файл чертежа (PDF или изображение) в область загрузки или нажмите кнопку "Выберите файл"
3. Дождитесь завершения анализа
4. Просмотрите найденные нарушения в списке справа
5. Используйте кнопку "Показать/скрыть нарушения" для управления отображением нарушений на чертеже

## Локальная разработка

1. Клонируйте репозиторий:

```bash
git clone https://github.com/evgeniy-kachan/construction-norms-analyzer.git
```

2. Откройте `index.html` в браузере или используйте локальный сервер:

```bash
python -m http.server 8000
```

3. Откройте http://localhost:8000 в браузере
